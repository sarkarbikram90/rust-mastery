# Contributing

Use:
- members/journal.md for personal notes


## Pull Requests

- Keep PRs small
- First git status, then git pull origin main, then git add . , then git commit -m "message", then git push origin main, then create PR on github
- Explain what you learned
- Link the related issue/resources
- Make sure code builds and tests pass

## Review Culture

We review to learn, not to judge.
Use comments like:
- Question: .......
- Idea: ........

## Definition of Done

A task is done when:
- code works
- README or notes are updated
- at least one learning takeaway is written
- one teammate has reviewed it
