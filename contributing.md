# Contributing

Use:
- members/journal.md for personal notes


## Pull Requests

- Keep PRs small
- Always do a git pull before pushing
- Explain what you learned
- Link the related issue/resources
- Make sure code builds and tests pass

## Review Culture

We review to learn, not to judge.
Use comments like:
- Question: .......
- Idea: ........

## Definition of Done

A task is done when:
- code works
- README or notes are updated
- at least one learning takeaway is written
- one teammate has reviewed it
